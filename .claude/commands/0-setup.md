Siapkan boilerplate di folder ini. Jangan membuat desain apa pun.

1. Cek dokumentasi resmi terbaru Astro, Tailwind, Keystatic (integrasi Astro), dan adapter Vercel.
   Tulis ringkasan langkah yang akan kamu jalankan dan tunggu persetujuan saya.
2. Setelah disetujui: buat proyek Astro (minimal/kosong), pasang Tailwind, Keystatic
   (storage mode `local`), dan adapter Vercel agar layar edit Keystatic bisa jalan
   sementara halaman situs tetap statis.
3. Pastikan `npm run dev` berjalan dan halaman `/keystatic` bisa dibuka.
4. Pasang Playwright (dev dependency) + browser Chromium saja.
5. Buat halaman index kosong berisi teks "setup ok". Tidak ada styling.
6. Jelaskan di akhir: struktur folder, perintah penting, dan apa yang perlu saya cek.
Berhenti setelah selesai.
